# 设备 B 打通清单（一页照做版）

> 目标：让第二台设备接入 GitHub 账号 `kee1027`，能 clone / pull / push 仓库。
> 预计 15–20 分钟。每步做完打勾。

## ☐ 第 1 步：装 Git（按设备 B 的系统选一个）

**Windows**：打开 https://git-scm.com/downloads/win 下载安装，全程默认下一步。装完桌面右键应出现 "Git Bash Here"。

**macOS**：终端执行 `brew install git`（或 `xcode-select --install`）

**Linux**：`sudo apt install git`（Ubuntu/Debian）

验证：打开终端（Windows 用 Git Bash），执行

```bash
git --version
```

## ☐ 第 2 步：配置身份（与设备 A 完全一致）

```bash
git config --global user.name "shy"
git config --global user.email "she1156547286@163.com"
git config --global init.defaultBranch main
git config --global pull.ff only

# Windows 设备 B 执行：
git config --global core.autocrlf true
# macOS / Linux 设备 B 执行：
git config --global core.autocrlf input
```

## ☐ 第 3 步：生成设备 B 自己的 SSH 密钥

```bash
ssh-keygen -t ed25519 -C "she1156547286@163.com-设备B"
```

一路回车（密码可留空）。然后显示公钥：

```bash
cat ~/.ssh/id_ed25519.pub
```

复制输出的**整行**（`ssh-ed25519` 开头）。

## ☐ 第 4 步：把公钥添加到 GitHub

1. 打开 https://github.com/settings/ssh/new （登录 `kee1027`）
2. Title 填 `设备B`，Key 粘贴公钥整行
3. 点 **Add SSH key**

验证：

```bash
ssh -T git@github.com
```

首次会问 yes/no，输入 `yes`。看到 `Hi kee1027! You've successfully authenticated...` 即成功。

## ☐ 第 5 步：克隆仓库

```bash
# 进入想放项目的目录（Windows 示例：D 盘 projects）
cd /d/projects        # macOS/Linux: cd ~/projects

git clone git@github.com:kee1027/rag-tutorials.git
cd rag-tutorials
git log --oneline     # 能看到 "初始提交：EEQS 智能问答教程与 Git 双设备部署指南" 即成功
```

## ✅ 完成

此后日常只用三条命令（详见同目录《手动操作日常指南》）：

```bash
git pull                                   # 开工先拉
git add . && git commit -m "改动说明"       # 提交
git push                                   # 收工推
```
