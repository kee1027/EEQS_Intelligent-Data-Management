# 03 · 首次克隆与提交工作流（设备 A）

> 本章在**设备 A**（你的主力设备）上完成：把 GitHub 上的空仓库克隆到本地，放入代码，完成第一次 commit 和 push，走通整个闭环。

---

## 3.1 理解 Git 的三个区域

动手前先建立心智模型，之后所有命令都是在这三个区域之间搬运改动：

```
工作区              暂存区             本地仓库            远程仓库
(你编辑的文件)  →   (git add)    →   (git commit)   →   (git push)
                                        ↑
                        用 git status 随时查看改动处于哪个区域
```

- **工作区**：你正常写代码、改文件的地方。
- **暂存区**：`git add` 把"准备提交"的改动先放进来，攒一批再提交。
- **commit**：把暂存区的改动拍成一张永久快照，附一句说明。

---

## 3.2 克隆仓库到本地

打开终端（Windows 用 Git Bash），进入你想存放项目的目录，然后克隆：

```bash
# Windows 示例：放到 D 盘的 projects 目录
cd /d/projects

# macOS/Linux 示例：
cd ~/projects

# 克隆（地址换成 02 章复制的你自己的 SSH 地址）
git clone git@github.com:<你的用户名>/my-project.git

# 进入项目目录
cd my-project
```

克隆完成后，这个文件夹就是一个完整的 Git 仓库了（里面有个隐藏的 `.git` 目录存放全部历史，**不要手动删它**）。

验证远程关联：

```bash
git remote -v
# 期望输出：
# origin  git@github.com:<你的用户名>/my-project.git (fetch)
# origin  git@github.com:<你的用户名>/my-project.git (push)
```

---

## 3.3 第一次提交：完整闭环

在 `my-project` 文件夹里创建/放入你的代码文件。以创建一个 README 为例：

```bash
# 创建一个新文件（也可以直接用编辑器写代码）
echo "# My Project" > README.md
```

然后走标准三步：

```bash
# 第 1 步：查看当前改动状态（高频命令，随时可用）
git status

# 第 2 步：把改动加入暂存区
git add README.md        # 添加指定文件
# 或者一次性添加所有改动：
git add .

# 第 3 步：提交，附一句清晰的说明
git commit -m "初始提交：添加 README"
```

推送到 GitHub：

```bash
git push -u origin main
```

> `-u origin main` 只需第一次推送时使用，作用是把本地 `main` 分支与远程 `origin/main` 绑定。之后直接 `git push` 即可。

打开 GitHub 仓库网页刷新，能看到 README.md 就说明**整条链路已打通** 🎉

---

## 3.4 日常修改代码的标准循环

此后每一天的工作就是重复这个循环：

```bash
# 1. 改代码（用任何编辑器，正常改文件）

# 2. 看看改了什么
git status              # 哪些文件变了
git diff                # 具体改了哪些行（未 add 的改动）

# 3. 暂存 + 提交
git add .
git commit -m "修复登录页校验逻辑"

# 4. 推送
git push
```

**commit message 写法建议**（未来的你会感谢现在的你）：

- 用一句话说明"做了什么、为什么"，如 `添加用户注册接口`、`修复导出 Excel 乱码`
- 一个 commit 只做一件事；一天可以有多个 commit
- 避免 `update`、`修改`、`123` 这类无信息量的说明

## 3.5 加一个 .gitignore（几乎每个项目都需要）

有些文件不该进仓库（依赖目录、编译产物、密钥、IDE 配置等）。在项目根目录创建 `.gitignore` 文件：

```gitignore
# 依赖
node_modules/
__pycache__/
.venv/

# 编译产物
dist/
build/
*.o

# 环境与密钥（永远不要提交！）
.env
*.pem
*.key

# IDE / 系统
.idea/
.vscode/
.DS_Store
Thumbs.db
```

提交它：

```bash
git add .gitignore
git commit -m "添加 .gitignore"
git push
```

> 按语言生成的 .gitignore 模板可参考：https://github.com/github/gitignore
